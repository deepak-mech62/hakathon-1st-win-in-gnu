# hakathon-1st-win-in-GNA University
An IoT-based smart gas detection system that detects LPG gas leaks, triggers a warning buzzer, automatically shuts off the gas regulator, sends mobile alerts, and notifies the user before the gas level gets low.
## Key Features
- **Gas Leak Detection:** Uses sensors to detect LPG leaks immediately.
- **Audio Alarm:** Triggers an automatic buzzer alert when a leak is detected.
- **Automatic Gas Cut-off:** Automatically turns off the regulator valve.
- **Mobile Notifications:** Sends instant SMS/App alerts to mobile phones.
- **Low Gas Level Warning:** Alerts user before the cylinder runs empty.

## Tech Stack
- **Hardware:** Gas Sensor, Arduino / ESP8266, Servo Motor, Buzzer, GSM/Wi-Fi Module.
- **Software:** Arduino IDE, C/C++, IoT Cloud Platform.
